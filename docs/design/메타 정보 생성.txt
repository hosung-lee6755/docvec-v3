**최종 갱신**: 2026-11-17 (코드 HEAD 0f38033 기준으로 필드마다 대조함)

이 문서는 메타 정보 설계 항목을 실제 코드와 대조한 결과다. 각 항목의 상태는 다음 뜻이다. 구현은 코드에 있고 값이 채워진다. 부분 구현은 일부 경로나 조건에서만 값이 채워진다. 별칭은 다른 컬럼이 같은 값을 담고 있다. 미구현은 코드가 없다. 절 번호는 코드 주석과 `문서데이터 전처리 방안.md`가 참조하므로 바꾸지 않는다.

**2절. 요소 및 구조 노드 메타정보 (Phase 3~5)**
위치: 요소는 `Document.elements`(JSON, `backend/app/pipeline/adapters/docling_adapter.py`가 만든다), 구조 노드는 `document_nodes` 테이블(`backend/app/db/models/document_node.py`)

**2-1. 요소 (Element)**

| 필드 | 설명 | 상태 | 코드 기준 |
|---|---|---|---|
| element_id | 요소 ID | 구현 | 요소의 `id`. Docling 경로에서 UUID를 부여한다. 구조 노드의 `element_id` 컬럼(`document_node.py`)은 노드가 속한 레이아웃 요소 ID를 담고, 청크 생성 때 청크의 `element_id`로 복사된다 |
| document_id | 문서 ID | 구현 | 요소는 `Document.elements`에 속하므로 문서 ID로 조회한다 |
| page | 페이지 | 구현 | 요소의 `page` 키 |
| order | 읽기 순서 | 구현 | 요소의 `order` 키 |
| type | heading, paragraph, table, image 등 | 구현 | 요소의 `type` 키. Docling 라벨과 `table`, `picture`, `vlm_ocr` 값을 쓴다 |
| bbox | 위치 | 구현 | 요소의 `bbox` 키. 위치 정보가 없으면 None이다 |
| parent_section | 상위 섹션 | 별칭 | `section_path` 배열이 같은 역할을 한다 |
| heading_level | H1~H6 | 부분 구현 | 요소 JSON에는 별도 키가 없다. 제목 수준은 구조 노드의 `level`에 저장한다. HWP와 HWPX는 구조 분석 레이아웃의 `heading_level`에서 얻는다 |
| style | Normal, Heading1 등 | 부분 구현 | Docling 경로는 None이다. 스타일 정보가 있는 DOCX 등에서 채운다 |
| font_size | 글자 크기 | 부분 구현 | DOCX, PDF, HWPX, HWP에서 채운다. Docling 경로는 None이다 |
| font_name | 글꼴 | 부분 구현 | DOCX와 PDF(Legacy 엔진)에서 채운다. Docling 경로는 라이브러리가 글꼴을 노출하지 않아 비어 있다 |
| is_header | Header 여부 | 부분 구현 | 키는 있다. 값을 정하는 기준은 7.5절의 반복 머리글 판정을 따른다 |
| is_footer | Footer 여부 | 부분 구현 | 키는 있다. 값을 정하는 기준은 7.5절의 반복 꼬리글 판정을 따른다 |
| is_caption | Caption 여부 | 구현 | Docling 라벨이 캡션에 해당하면 true다 |
| image_path | 이미지 파일 | 부분 구현 | 그림은 `images/{문서 ID}/{번호}.png`로 아티팩트 버킷에 저장된다. 요소의 `image_path`는 `_match_image_paths`가 그림 인식 결과와 맞춰 채운다. 실제 저장 값은 이번 점검에서 확인하지 못했다 |
| table_rows | 행 개수 | 구현 | 표 요소의 `table_rows` |
| table_cols | 열 개수 | 구현 | 표 요소의 `table_cols` |

**Phase 9. Parent Retrieval 구현 내용**
- 부모 청크는 자식 청크 5개를 평면 그룹으로 묶어 만든다(`group_children_into_parents`). 부모 길이 상한은 자식 길이 상한의 4배다(`_PARENT_SIZE_MULTIPLIER`).
- 검색 결과에 붙이는 부모 문맥은 `services/parent_context.py`가 최대 1200자까지 덧붙인다(`PARENT_CONTEXT_MAX_CHARS`). 설정 `parent_context`의 기본값은 켜짐이다.
- 품질 검증과 재처리 영향도는 부모 청크를 세지 않는다(자식 청크만 센다).
