# docs — 문서 안내

프로젝트의 모든 문서는 이 폴더에서 관리한다. 처음 보는 사람은 `인수인계서.md`부터 읽는다.

| 위치 | 내용 |
|---|---|
| `인수인계서.md` | 새 작업자의 입구 문서 — 현황, 기동 방법, 보류 항목, 첫날 체크리스트 |
| `유지보수_가이드.md` | 장애 대응, 운영 명령어, 외부 접속, 코드 확장 방법 |
| `기술문서_시스템_아키텍처.md` | 현재 구현이 어떤 알고리즘·수식·임계값으로 동작하는가 |
| `design/` | **현행 설계서** — 설계 의도, 화면/데이터 구조. 구현과 갈린 곳은 "⚠ 실제 구현과 차이" 콜아웃으로 표시 |
| `design/메타 정보 생성.txt` | 문서·청크 메타정보 항목 정의(코드 주석의 "메타 정보 생성.txt N절"이 이 파일) |
| `design/문서데이터 전처리 방안.md` | 전처리 단계(정제·사전·PII·구조·청킹) 기준 문서 — 모델·블록 docstring이 § 번호로 참조 |
| `plan/` | **초기 기획·상세 설계 자료**(1. 구조 설계 ~ 7. 고도화 설계, 통합본 `MASTER_INTEGRATED_KO_UPDATED (1).md`). 최초 설계 시점의 기록이라 현행 구현과 다를 수 있다 — 구현 기준은 `design/`과 기술문서를 우선한다 |
| `참고/` | 보조 자료 — 기술 브로셔(`DocVec_기술브로셔.html`), E2E 검증 보고서, 서버 접속 주소 메모(내부 IP 포함, 저장소에는 올리지 않는다) |

문서 간 우선순위는 **현행 설계서(`design/`) > 기술문서 > 초기 기획(`plan/`)** 이다.
