1. Document Metadata(문서 메타정보)
| 필드             | 설명                           | 검색 활용 |
| -------------- | ---------------------------- | ----- |
| document_id    | 문서 UUID                      | 문서 고유 ID|
| file_name      | 원본 파일명                       | 출처    |
| source_path    | 저장 경로                        | 다운로드  |
| file_type      | pdf/docx/hwp/hwpx            | 필터    |
| title          | 문서 제목                        | 검색    |
| summary          | 문서 요약                        | 문서 탐색, 라우팅    |
| author         | 작성자                          | 필터    |
| organization   | 부서/기관                        | 필터    |
| created_at     | 작성일                          | 정렬    |
| modified_at    | 수정일                          | 정렬    |
| language       | ko/en                        | 검색    |
| page_count     | 총 페이지                        | UI    |
| checksum       | SHA256                       | 중복 제거 |
| parser_version | 파서 버전                        | 재색인   |
| ingestion_time | DB 저장 시각                     | 관리    |
| tags           | 태그                           | 필터    |
| category       | 계약서/보고서/매뉴얼                  | 필터    |
| security_level | Public/Internal/Confidential | 권한    |
| source_system  | SharePoint, S3 등             | 관리    |
