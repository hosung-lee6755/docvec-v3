Core Capabilities

Hybrid LLM Architecture
로컬 모델 + 클라우드 모델, 작업 단위로 선택

온프레미스 로컬 모델로 민감 데이터를 처리하고, 필요할 때만 OpenAI·Anthropic 등 클라우드 모델을 사용합니다. API 키는 프로젝트 또는 개인 단위로 암호화 보관되어 비용과 데이터 주권을 함께 통제합니다.

Retrieval
하이브리드 · 시맨틱 검색

다국어 임베딩과 Qdrant 벡터 DB로 의미 기반 검색을, 키워드 검색과 결합해 재현율을 보완합니다.

Grounded Answers
출처 인용 RAG 채팅

모든 답변에 근거가 된 문서·페이지·컬렉션을 함께 표시해 추적과 검증이 가능합니다.

Multi-Tenancy
프로젝트 단위 데이터 격리

컬렉션 · API 키 · 시스템 프롬프트를 프로젝트별로 분리해 팀 · 고객 단위로 독립 운영합니다.

Governance
역할 기반 접근 제어

Owner · Editor · Viewer 권한 체계로 문서와 컬렉션 접근을 세밀하게 통제합니다.

Async Pipeline
비동기 처리 아키텍처

작업 큐 기반으로 대용량 문서를 백그라운드에서 처리하고, 처리 상태를 실시간으로 추적합니다.
